# NEXORA — Premium AI SaaS Template

A polished, responsive React + TypeScript + Vite landing page designed for SaaS, AI automation, productivity and startup products.

## Included
- Responsive navigation
- High-conversion hero section
- SaaS analytics dashboard mockup
- Feature cards
- 3-step workflow section
- Testimonial
- Pricing cards
- Interactive FAQ
- CTA section
- Responsive footer
- Mobile layout

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Deployment
Works with Vercel, Netlify, Render Static Site and any host that supports Vite static builds.

Replace demo copy, brand assets and testimonials before commercial delivery.

Template license: intended for one end-client/project per purchased license unless the seller's marketplace license states otherwise.
